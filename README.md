# Telegram Bot с динамической сменой ролей и режимом 24/7

Полнофункциональный Telegram-бот на базе **`aiogram 3`** и **OpenAI API** (или любого совместимого API: OpenRouter, DeepSeek, Ollama), позволяющий каждому пользователю самостоятельно задавать системный промпт (роль/характер/инструкции) и вести диалог в соответствии с этой схемой.

---

## 🌟 Возможности

- **Индивидуальная роль для каждого пользователя**: каждый пользователь настраивает свою роль независимо от других.
- **Интерактивная настройка**: поддержка задания промпта как в одну команду (`/setrole Текст...`), так и через пошаговый диалог (FSM).
- **Сохранение в базе данных (SQLite)**: роли и контекст диалога сохраняются между перезапусками бота.
- **Поддержка любых LLM**: OpenAI GPT-4o, OpenRouter, DeepSeek, локальные модели через Ollama.
- **Режим 24/7 и автоперезапуск**: защита от падений, автореконнект при обрыве сети и готовые сценарии автозапуска.

---

## 📋 Команды бота

| Команда | Описание |
|---|---|
| `/start` | Приветствие и быстрый гид по боту |
| `/setrole` (или `/setprompt`) | Установить новую роль/системный промпт |
| `/getrole` (или `/getprompt`) | Показать текущую активную роль |
| `/clear` | Очистить историю диалога (роль сохраняется) |
| `/reset` | Сбросить роль на базовую и очистить историю |
| `/help` | Справка и примеры промптов |
| `/cancel` | Отменить текущий ввод роли |

## 🛠 Настройка конфигурации (.env)

Заполните файл `.env`:
```env
TELEGRAM_BOT_TOKEN=ваш_токен_от_BotFather
OPENAI_API_KEY=ваш_api_ключ
OPENAI_BASE_URL=
LLM_MODEL=gpt-4o-mini
MAX_HISTORY_MESSAGES=10
```

## 🚀 Варианты запуска 24/7

### Вариант 1: На Windows (Автоперезапуск через скрипт)
Запустите файл [run_24_7.bat](file:///C:/Users/jamsen/.gemini/antigravity/scratch/custom_role_telegram_bot/run_24_7.bat):
```cmd
run_24_7.bat
```
*Скрипт будет автоматически перезапускать бота при любых сбоях или отключениях сети.*

---

### Вариант 2: В Docker (Кроссплатформенно)
```bash
docker compose up -d --build
```
*Контейнер запускается в фоновом режиме с политикой `restart: always`.*

---

### Вариант 3: На удаленном сервере Linux (systemd)
1. Скопируйте папку проекта на сервер (например, в `/opt/custom_role_telegram_bot`).
2. Скопируйте файл сервиса:
   ```bash
   sudo cp bot.service /etc/systemd/system/telegram_bot.service
   ```
3. Активируйте и запустите:
   ```bash
   sudo systemctl daemon-reload
   sudo systemctl enable telegram_bot
   sudo systemctl start telegram_bot
   ```
4. Проверить статус:
   ```bash
   sudo systemctl status telegram_bot
   ```
